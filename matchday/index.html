Matchday: a football tracker built around the player's position

Most match trackers assume every player is a striker and count goals and assists. Matchday starts with the player's position and scores what matters for that role.

What each position scores

PositionScored on
GoalkeeperSaves, clean sheets, save percentage
DefenderTackles, interceptions, clearances
MidfielderChances created
ForwardShots, conversion

Features

  • Offline-first installable web app
  • Match calendar
  • 0 to 100 match score with a visible breakdown
  • Tournament tracking
  • Training log
  • AI coach (drill sessions and short-clip feedback)
  • Family sharing
  • An academy side with consent controls

The build

  • About10weeks of build
  • 77commits
  • Roughly27,000lines of TypeScript
  • About465automated tests

Claude Code wrote most of the code under the founder's direction.

Status

Live as a web app and free to use. Not yet in the App Store or Play Store.
